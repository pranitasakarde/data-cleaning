# 🧹 Data Cleaning using Python

A data cleaning project developed in **Jupyter Notebook** to clean, preprocess, and prepare raw data for analysis.

### 🛠️ Technologies

* Python
* Pandas
* NumPy
* Jupyter Notebook

### ✨ Data Cleaning Steps

* Handling missing values
* Removing duplicates
* Correcting data types
* Handling inconsistent data
* Data formatting
* Basic data validation

### 📓 Notebook

`data_cleaning.ipynb`

### 🎯 Objective

To transform raw and inconsistent data into a clean and analysis-ready dataset.
